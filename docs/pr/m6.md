# M6: Hardening

## What changed

### Search and sharing

- **`lib/seo.ts`:** `pageMetadata()` gives every page its title, description (from the page's lead in the deck or appendix), canonical URL, Open Graph and Twitter card.
- **`metadataBase`** comes from `NEXT_PUBLIC_SITE_URL`, then Vercel's production URL, then localhost.
- **Social cards** via `next/og`:
  - a site card (the Home headline on ink)
  - one card per case (its name on its stage colour)
  - drawn in Special Gothic: the OFL TTFs are vendored in `apps/anneal/assets/fonts` with their licence, because `next/og` needs TTF
- **Fixed during testing:** a page's own `openGraph` replaced the inherited site card, so most pages shared no image. `pageMetadata` now names the card, and the cases' own card files still win.
- **`sitemap.xml`:** every public page and case.
- **`robots.txt`:** allows the site; disallows `/kitchen-sink` and `/api/`, which is also `noindex`.
- **JSON-LD:** an `Organization` on Home, using only facts the site states.

### 404

`app/not-found.tsx`, with the site chrome. The deck has no 404 wording, so it shows "404" and the site's own navigation labels. Nothing is invented (open question below).

### Icons

- `app/icon.svg`: the four-cell mark on ink.
- `app/apple-icon`: the same, rendered at 180px.

### Security headers

On every response:

- `X-Content-Type-Options: nosniff`
- `X-Frame-Options: DENY`
- `Referrer-Policy: strict-origin-when-cross-origin`
- `Permissions-Policy` (camera, microphone and geolocation off)
- `Strict-Transport-Security`

### Content review

- Every page was rendered and scanned for leftovers (TODO, lorem, `undefined`, `NaN`, unfilled brackets, dashes).
- The only hit is `[registered address]` on Privacy, which the appendix asks to keep visible until the address is supplied.

## Decisions and deviations

1. **No Content-Security-Policy yet.** The boot script and JSON-LD are inline, so a CSP needs nonces through middleware, which would make every page dynamic. Recommended after launch as report-only first.
2. **The kitchen sink stays deployed,** as a review page for the kit, but it is out of the sitemap and not indexed.
