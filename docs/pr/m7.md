# M7: Template starter and a second site

## What changed

### `packages/create-studio-site`

- A Node CLI with no dependencies, run as `pnpm create-site <name> [--title] [--accent] [--ink] [--ground] [--panel]`.
- It copies `template/` into `apps/<name>` and fills in the package name, site title and theme.
- The accent's text colour is computed: ink or white, whichever reads better on it.
- It refuses:
  - names that cannot be both a folder and a package
  - colours that are not hex
  - ink under 4.5:1 on the ground
  - an existing app folder

### The template

A complete, small site on `packages/kit`:

- the header, floating nav, cursor label and "start a project" hand-off transition
- Home: masked hero with a morphing tile, a case stack whose cards grow into their case (`CoverLink`), and process steps lit by scroll
- one MDX case written with the kit's case sections (header, stage, brief, questions, principle, features)
- a contact page
- the sticky closing and the glass footer with physics tiles and the stretching wordmark

The template's copy is all in `content/site.ts` and the example MDX. It is placeholder text, said so in the file, and meant to be replaced. None of it is Anneal copy. The theme is on `:root` in `app/globals.css`, and the faces are in `app/fonts.ts`.

### `apps/demo` ("North Light")

- Generated by the CLI with a warm theme: ground `#f1ede4`, ink `#1b1a17`, accent `#e4572e`.
- Its display face is Oswald where Anneal uses Special Gothic.
- It builds, lints and typechecks in CI.
- A test regenerates it and fails if any file differs, so a broken template cannot slip past CI.

### Kit

No API changes. Comments and test fixtures no longer mention Anneal's cases.

## Dependencies

None new. The template pins the same versions as `apps/anneal`.

## How it was tested

- **Vitest:** 8 tests for the CLI:
  - name and colour validation
  - accent text contrast
  - placeholders all filled
  - no overwrite
  - the demo matches a fresh generation
- `apps/demo`: `next build`, `tsc` and ESLint pass, and CI now builds it.
- **Manual:** Home and the example case checked at 1440 in Chromium, scrolled through with full motion. Reveals, the stack, the steps, the closing marquee and the footer all work, with no console errors.

## Decisions

- **Plain `.mjs` for the CLI,** so it runs with Node alone and needs no build.
- **The demo is the template's integration test.** Rather than a separate fixture, the committed demo is the generator's exact output, and CI builds it.
