# M0 and M1: monorepo, tokens, fonts, CI, motion engine and shared UI

Ideally this lands as two PRs (M0 then M1). The repo had no git history, so it is written up as one; the split point is listed at the end.

## What changed

### M0: monorepo, tokens, fonts, CI

- pnpm workspace and Turborepo: `apps/anneal` (`@anneal/site`), `packages/kit` (`@studio/kit`), `packages/config` (`@studio/config`).
- TypeScript strict everywhere, plus `noUncheckedIndexedAccess`. ESLint flat config with `strictTypeChecked`: no `any`, no `@ts-ignore`, no non-null assertions, React hooks, jsx-a11y (strict) and the Next.js Core Web Vitals rules.
- `scripts/check-dashes.mjs` fails lint on any em or en dash in shipped source, comments included.
- Tailwind CSS v4. The kit ships neutral `@theme` tokens; Anneal sets its values on `:root` in `app/globals.css` (from `design/README.md`).
- Fonts through `next/font/google`, self-hosted at build time. Only the condensed display face (the hero headline, the LCP element) is preloaded. next/font has no fallback metrics for Special Gothic, so each face has a size-adjusted Arial fallback whose values come from next/font's own routine run on the font files. Geist Mono falls back to Courier New: both use a 0.6em advance, whereas next/font's default Arial fallback set labels 38% wider and caused a 0.09 CLS.
- Boot script inline in `<head>`. It sets three things on `<html>` before first paint:
  - `data-motion`: hidden and animated states only apply under `full`, so without JS everything renders visible and still.
  - `data-currency`: from a cookie, so static pages show the right price on first paint.
  - `data-handoff`: lets the Work with us overlay cover a hard navigation from the first frame.
- Currency middleware: on a first visit, the currency comes from `x-vercel-ip-country` (NG → NGN, euro area → EUR, everywhere else USD) and is remembered in a cookie. Pages stay static.
- Typed content: `content/copy.ts` (deck keys, word for word), `content/prices.ts` (the only place prices live), `content/currency.ts`, `content/site.config.ts`.
- CI: format, lint, typecheck, Vitest, then Playwright (smoke, axe, visual) and the Lighthouse budget in parallel. A manual workflow regenerates the linux visual baselines.

### M1: motion engine and shared UI

All motion goes through `packages/kit/motion`: one GSAP ticker, Lenis smooth scroll synced to ScrollTrigger, a shared IntersectionObserver registry and a single scroll subscription. Every primitive has a reduced-motion path and pauses off screen.

  - Kit: physics, marquee maths, cubic-bezier easing, the hand-off flag, contrast maths, clock formatting, the serialised boot script, `CurrencySwitch` and `MotionToggle`.
  - App: every `copy.ts` value matches `docs/copy-deck-v3.md`; `prices.ts` matches the `build-handoff.md` table row for row; currency mapping; Anneal token pairs meet WCAG AA.

  - Smoke in Chromium, WebKit and mobile WebKit (iPhone 15):
    - boot attributes
    - currency default from the country header, and the switch persisting across a reload
    - the reduced-motion switch moving every primitive to its static path and back
    - OS reduced motion being honoured
    - floating nav visibility and microcopy
    - Work with us: the morph, the arrival after a full reload, stale flags being ignored, and plain navigation with reduced motion
    - the keyboard throw
    - the hidden nav being inert
    - no horizontal overflow
  - axe (WCAG 2.2 AA tags) on `/`, `/kitchen-sink` and `/start`, with and without reduced motion.
  - Visual snapshots at 1440, 1024, 768 and 390 for all three pages.

## Spec questions

I picked the option closest to the board where I could. Where the board conflicts with AA, AA won, as CLAUDE.md requires.

1. **Copy that is on the boards but not in the deck.** This covers:
   - nav labels
   - "Work with us"
   - "Say hello", "Prices in", "LinkedIn · X · Instagram"
   - "© 2026 Anneal Studio", "Made in Lagos and Barcelona", "Privacy", "Back to top ↑"
   - "View case", "I need", the hero rows

   They are in `boardCopy` (copy.ts), taken verbatim from the boards. Should they move into the deck?
2. **Inner-page floating nav messages** ("Small studio, two cities.", "Come and build something with us.", "You made it to the bottom. Thanks.") exist only in the board scripts. Inner pages use `home.msg.8` and `home.msg.9` for now.
3. **Accent button text.** The board's ink `#0B0B0C` on `#7A5CFF` is 4.497:1, just under AA for 14px text. `--color-on-accent` is `#000000` (4.80:1). OK?
4. **Unlit and inactive text.** WordLight `#CFCFCF` and the principles `#A6A6A6` fail AA on white (1.5:1 and 2.4:1). They use `#767676` (4.54:1), which makes the effect subtler.
5. **Other dimmed text.**
   - The "I need" prefix (`#8A8A8A` on the ground, 2.4:1) uses `#5C5C5C`.
   - The process counter's "/05" (`#3A3A3A` on ink, 1.8:1) uses `#7A7A7A`.
   - The current header link is dimmed with colour rather than 45% opacity.
6. **Euro default.** It covers the 21 euro-area members (Bulgaria included from 2026). Should Andorra, Kosovo, Monaco, Montenegro, San Marino and Vatican City also default to EUR?
7. **Lighthouse method.** The budget runs with DevTools throttling. Lantern's default simulation scores the same build at about 2.8s LCP against localhost, because it models from an unthrottled trace where all scripts run before first paint. Real throttling measures about 1.4s. Is that acceptable, or should the simulated score count against preview URLs instead?
8. **Small-screen navigation.** The boards hide the header links below 900px and offer no menu, so on phones Work, Services, Products and Studio are reachable only from the footer. Add a menu?
9. **Keyboard hint for the physics tiles.** The playground is a focusable button (Enter or Space throws the tiles), but there is no visible hint for keyboard users. Need copy?
10. **No skip link.** Landmarks satisfy WCAG 2.4.1, but a skip link would need copy.
11. **`/kitchen-sink` in production.** It is `noindex`. Keep it public for template buyers, or gate it?
