# **TITLE**

A studio site generated by `create-studio-site` from the kit in `packages/kit`.

- `content/site.ts`: the name, navigation and every line of copy. Replace the placeholder text.
- `content/cases/`: case studies as MDX, written with the kit's case sections.
- `app/globals.css`: the theme (colours on `:root`) and `app/fonts.ts` (faces).

```sh
pnpm install
pnpm --filter @sites/__NAME__ dev
```
